# Benchmark version

The [v3 tag](https://github.com/Lizn-zn/Lean4Commit0/tree/v3) identifies the public revision of Lean4Commit0. It has 108 library tasks, with 511 implementation and 521 proof obligations.

The P³ experiments used the original benchmark version, which had 511 implementation and 519 proof placeholders. V3 revises contracts, editable boundaries, and the standalone checker. It adds two proof obligations for PyJWT and Serde. The paper reports measurements for the original version.

The original snapshot is preserved separately. Its source provenance identifies commit `0e91089e55c230e40e4c8e9fa946d556832294e4`.
